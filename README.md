# Can Narcís

Web de Can Narcís, masia del 1688 a Casavells (Baix Empordà).
Publicada a https://alexfont21.github.io/can-narcis/

## Com fer canvis

1. Edita `src/plantilla.html` (textos a l'objecte `T`, fotos a `GAL` i `LLOCS`).
2. Executa `python3 build.py`: genera les pàgines de cada idioma
   (`index.html`, `es/`, `en/`, `fr/`, `it/`, `de/`) i `sitemap.xml`.
3. Puja els canvis a la branca `main`.

No editis directament els `index.html`: es tornen a generar a partir de la plantilla.
